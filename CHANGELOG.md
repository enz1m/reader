# Changelog

## 0.1.1

- Reader is available on enzim Apps. Open a PDF, EPUB, or CBZ, search inside documents, and return to where you left off.
- The sidebar transitions more smoothly when you show or hide it.

## 0.1.0 — initial source release

- PDF, EPUB and CBZ reading, recent documents and restored progress.
- Search, bookmarks, notes, highlights and native document transfers.
- PDF page arrangement, metadata, password and signature tools.
- Public enzUI Alpha 0.1, system/theme interface fonts and shared theme settings.
